# calculadora-java
Una calculadora hecha en Java.
Funciones:
- sumar() -> Suma 2 números. a + b
- restar() -> Resta 2 números. a - b
- multiplicar() -> Multiplica 2 números. a * b
- dividir() -> Divide el primer número entre el segundo. a / b, con control de cero
- potencia() -> Eleva la base al exponente. base^exponente
- modulo() -> Saca el cociente de la división del primer número entre el segundo. a % b
- raiz_cuadrada() -> Calcula la raiz cuadrada del primer número. 2√a

Ejemplos:
sumar(2, 2) = 4
dividir(5, 0) = Error. No se puede dividir entre 0
raiz_cuadrada(16) = 4

Requisitos:
- Windows, MacOS o Linux
- Versión de Apache Netbeans compatible con Java 21
- JDK 21

Como compilar:
1. Abre el proyecto en Netbeans con JDK 21 instalado previamente.
2. Dale al botón "Build Project"
